# Comparing the fate of eDNA by particle sizes and molecule lengths in recirculating streams

[https://doi.org/10.5061/dryad.nvx0k6f32](https://doi.org/10.5061/dryad.nvx0k6f32)

## Description of the data and file structure

This directory contains supplementary figures to the manuscript, as well as the raw data used in the manuscript. If further information is required to replicate the findings of #this manuscript, please do not hesitate to contact me (Pedro Brandão, corresponding author of the manuscript)

**File descriptions:**

* Raw_data_supplement_partsizevsmollength.csv 

This is the raw dataset, containing the ddPCR concentrations and other relevant information to derive the eDNA concentrations in each stream by treatment, filter size, and marker. Missing data given as NA. Columns are described in the metadata file in further detail

* Metadata.csv

This describes the columns in the raw data described above.

* Nested_supplement_R2.PDF

This is a file containing the supplemental figures for the manuscript, which are referenced in the main text
